# Flexus Agent 技能集合

[English README](README.md)

## 📖 简介

本仓库收录了基于 **Dify** 编排并导出的可复用工作流技能。每个技能都是一个独立的工作流文件，可以直接导入到 Dify 平台中使用。

**特点**：
- 🚀 **开箱即用**：下载后直接导入 Dify 即可使用
- 📂 **分类清晰**：按应用场景分类，便于查找
- 🔧 **持续更新**：定期新增和优化工作流
- 📝 **文档完善**：每个技能都有详细说明
